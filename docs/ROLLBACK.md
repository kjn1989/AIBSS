# 「流れ」と「チーム力」を撤回する

試して合わなければ、この2つの機能だけを取り消せるようにしてあります。

## 目印

| 名前 | 何の時点か |
|---|---|
| `before-flow` | 流れ・チーム力を**入れる前**。試合ルール(タイブレーク・守備人数・全員打ち)までは入っている |
| `with-flow` | 流れ・チーム力を**入れた後**。この文書を書いた時点の `main` |

```
git tag -n5 -l          # 目印の一覧と説明
git log before-flow..with-flow --oneline --first-parent   # 間に入ったもの
```

## 撤回するもの

`before-flow` に戻すと、以下が消えます。

- **流れタグ** — スコア入力画面の ▲流れ来た / ▼流れ切れた
- **試合の流れ** — 傾きのグラフ、大きく動いた区間、タグの答え合わせ(読み当て率・察知率)
- **チーム力** — 成績タブの8指標(決定力・火消し力など)
- **甲子園の実測得点期待値** — ブカツの土台に使っている4状況
- デモデータの打席前の状況(走者・アウト)

消えないもの: スコアシートの直接修正、回の流れ(交代のタイミング)、守備・交代の修正、
投手成績の修正、試合ルール。これらは `before-flow` の時点で既に入っています。

## 戻し方

### 方法1: 打ち消しのコミットを積む（履歴が残る・推奨）

`main` を書き換えないので、他の人が取得済みでも壊れません。
気が変わったらこの打ち消しをさらに打ち消せます。

```bash
git checkout main
git revert --no-commit before-flow..with-flow
git commit -m "流れ・チーム力を撤回する"
git push origin main
```

### 方法2: その時点まで巻き戻す（履歴を書き換える）

`main` を直接動かします。すでに誰かが取得していると衝突するので、
一人で使っているときだけ。

```bash
git checkout main
git reset --hard before-flow
git push --force-with-lease origin main
```

## 一部だけ残したいとき

機能ごとにコミットが分かれているので、選んで打ち消せます。

```bash
git log before-flow..with-flow --oneline --first-parent
```

| 残す/消す単位 | コミット |
|---|---|
| 流れタグ(押すだけ) | `流れタグをスコア入力画面に置く` ＋ `流れタグの取り消しに名前を付ける` |
| 流れの可視化と答え合わせ | `試合の流れの可視化と、流れタグの答え合わせ` ＋ `流れのグラフに目盛りを入れ…` |
| 甲子園の得点期待値 | `甲子園の実測得点期待値をブカツの土台に使う` |
| チーム力 | `チーム力(順位表なしで読める指標)を成績に足す` |

例: チーム力だけやめて流れは残す

```bash
git revert -m 1 <チーム力のコミット>
```

後ろのものから順に打ち消してください。チーム力は流れの計算(`src/lib/flow.js`)を
使っているので、流れを先に消すとチーム力が動かなくなります。

## 記録したデータについて

**流れタグを押した記録は `game.playLogs` に `kind: 'flow'` として入っています。**
機能を撤回してもデータは消えません(画面に出なくなるだけ)。
あとで戻したくなったら、そのまま答え合わせに使えます。

消したい場合は、スコアシート → 修正する → 回の見出し → 回の流れ から1件ずつ消せます。

**得点期待値は保存していません。** 打席の記録から毎回その場で計算しているので、
撤回しても余分なデータは残りません。
